# Operating Systems Projects

A collection of Linux-based Operating Systems projects developed in **C**, focusing on Linux file systems, permissions, file handling, system calls, and role-based access control.

## Projects

### 1. Hotel Management System

A Linux-based hotel management system developed in C to practice Linux file-system operations and system programming concepts.

**User Roles:**

* Admin
* Staff
* Guest

**Main Concepts:**

* File and directory management
* File permissions
* File handling
* Symbolic links
* File searching
* File copying and backups
* User roles and access control

---

### 2. Gaming Platform Management System

A Linux-based gaming platform management system developed in C to practice Linux file-system operations and system programming concepts.

**User Roles:**

* Admin
* Moderator
* Player

**Main Concepts:**

* Linux file-system operations
* File permissions
* File handling
* System calls
* File searching
* Copying and moving files
* Role-based access control

---
